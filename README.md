# CopilotRunner ![Static Badge](https://img.shields.io/badge/status-estable-green) ![Static Badge](https://img.shields.io/badge/uso-legal%20en%20la%20UE-lightblue) ![Static Badge](https://img.shields.io/badge/framework-.NET-blue)

**CopilotRunner** es una pequeña utilidad que permite ejecutar fácilmente **Microsoft Copilot** como aplicación independiente, incluso en regiones donde su uso aún no está oficialmente soportado (como países de la Unión Europea).

Este proyecto aprovecha el motor WebView2 para crear una interfaz ligera, sin navegador, enfocada en la productividad y en el acceso directo a Copilot.

---

## Características

- **Interfaz minimalista y sin distracciones**  
- **Carga directa de Copilot web** (copilot.microsoft.com)  
- **Sin necesidad de navegador**  
- **Soporte para login con cuenta Microsoft**  
- **100% funcional incluso en países con bloqueo por región**

---

## ¿Por qué?

Microsoft Copilot no estaba (o sigue sin estar) disponible oficialmente en algunas regiones. Esta herramienta permite acceder sin tener que cambiar DNS, instalar VPN o modificar el sistema.

---

## Requisitos

- Windows 11
- Cuenta Microsoft compatible
